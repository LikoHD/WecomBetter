# WecomBetter

企微搭子，企业微信文档 Chrome 插件。打开 [企微文档](https://doc.weixin.qq.com/) 后自动工作。

## 安装

1. Chrome 打开 `chrome://extensions`
2. 打开「开发者模式」
3. 「加载已解压的扩展程序」，选中本仓库根目录
4. 打开任意 `https://doc.weixin.qq.com/...` 文档

## 开发验证

安装依赖后运行 `npm test`。测试先构建两份注入脚本，再用本机 Chrome 执行 Playwright 回归；可通过 `PLAYWRIGHT_CHANNEL` 指定其他已安装的浏览器通道。

文档编辑回归使用本地页面和拦截的数据请求，不会修改线上文档。覆盖元信息挂载、更新及开关切换时的编辑区 DOM、标题和编号、选区、输入、滚动、窄屏及普通文档画布。线上编辑器的实际行为仍需在测试文档中复验。

插件 UI 不应插入 `#root-editable`、原生块列表或其他可编辑子树。创建人信息在编辑区外跟随标题定位；标题上方空间不足时隐藏，不通过插入节点或调整正文间距占位。

正文输入及中文组合输入期间，暂停全文引用采集和附加界面更新（包含异步头像），提交并停止输入 500ms 后再更新。普通文档开始编辑后停止当次自动 Web 版式切换；重新开启该功能才会重新尝试。测试覆盖输入法长时间选词、输入事件不被取消、停止输入后恢复采集。

修改后先构建，再在 `chrome://extensions` 重新加载插件，并对文档页硬刷新（macOS：`⌘⇧R`；Windows：`Ctrl+Shift+R`）。
